# 前言

当你在 GitHub 上点开这本《宁波诺丁汉大学计算机系飞跃手册》时，你或许正处于迷茫、焦虑，或是踌躇满志的时刻。

站在 2026 年的节点，计算机科学正经历着前所未有的变革。生成式 AI 的浪潮不仅重塑了行业的边界，也让 CS 的留学申请变得更加扑朔迷离。你可能会问：在一个只需要写几句 Prompt 就能让 AI 生成一篇结构优良的个人陈述（SOP）的时代，为什么我们还需要这样一本由前人一字一句敲出来的《飞跃手册》？

答案很简单：因为算法算不出离梦想的距离，AI 也无法替你走过那些至暗时刻。

机器不懂得你在应对众多 Coursework、熬夜 debug 时的艰辛，不懂期末时反复背诵名词定义时的痛苦，不懂得你看着一封封拒信时的自我怀疑，更不懂得当你终于点开 Dream School 邮件时的满心欢喜。这份手册里记录的，不是冰冷的“三围”数据（GPA、语言成绩、推荐信强度），而是一个个鲜活的 UNNCer 如何在迷茫中寻找方向，在试错中笃定前行的真实故事。

翻开这本手册，你会看到学长学姐们走向众多世界顶尖学府的足迹。你会发现，通往终点的路径远比你想象的多元：有人在 AI 的红海中杀出重围；有人在 Systems、HCI 或交叉学科的小径上深耕不辍；也有许多人作出了跨学科申请、乃至跨界就业的勇敢尝试；有人是按部就班的“全能选手”，也有人讲述了自己低谷反弹的“逆风翻盘”。

在此，我们要写给每一位正在翻阅此册的申请者：请不要把这本手册当作衡量自己的“焦虑制造机”。当你看到满屏光鲜亮丽的录取结果时，请记住，榜单只是幸存者偏差的缩影，手册的意义是一张供你探索未知海域的“航海图”，而不是一把丈量你优秀的“标尺”。找到属于你的旷野，远比挤上别人的轨道更重要。

UNNC 计算机系或许不是最顶尖、最完美的平台，课内讲授的内容也不足以让大部分人直接胜任工业界的所有岗位，但这里也有着得天独厚的优势与极具韧性的土壤，而《飞跃手册》可谓是这片土壤上珍贵的果实。作为一本托管在 GitHub 上的开源手册，它完美诠释了 CS 领域的 Open Source 精神——薪火相传，生生不息。

最后，我们要特别感谢每一位将自己的血泪史与宝贵经验“开源”为一个个案例的历届撰稿人，以及辛勤维护此项目的编委会成员。是你们的无私分享，点亮了后来者前行的路。

勇敢地去向世界投递你的简历吧，不论是学术界还是工业界。愿你们在日后的每个人生阶段，都能完成属于自己的“飞跃”。
